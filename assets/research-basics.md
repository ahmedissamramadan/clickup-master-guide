# ملف مرجعي: أساسيات ClickUp، الميزات الأساسية (2025–2026)

> المصادر: ClickUp Help Center (help.clickup.com)، صفحة ClickUp الرسمية، وثائق ClickUp University، مراجعات مستقلة 2025–2026. الروابط في النهاية.

## 1. ما هو ClickUp؟

ClickUp منصة إدارة عمل ومشروعات سحابية أطلقتها شركة **Mango Technologies Inc.** في **2017**، على يد المؤسسين **Zeb Evans** و**Alex Yurkowski**، ومقرها سان دييغو، الولايات المتحدة. شعارها التسويقي الأشهر: **"One app to replace them all"**، تطبيق واحد يحل محل الأدوات المتفرقة (إدارة المهام + المستندات + الدردشة + الأهداف + السبورات البيضاء + تتبع الوقت). تجاوزت الشركة تقييم **4 مليارات دولار** في 2021 وتخدم ملايين الفرق وعشرات آلاف الشركات (منها IBM, Netflix, Google كعملاء معلنين سابقًا).

الفلسفة: بدلًا من أن يفرض المنتج طريقة عمل واحدة، يمنح ClickUp كل عنصر هيكلًا مرنًا (طرق عرض متعددة لنفس البيانات) وأتمتة قابلة للبناء بدون كود، مع طبقة ذكاء اصطناعي مدمجة (ClickUp Brain).

## 2. الهيكل الهرمي (Hierarchy)

الترتيب الكامل: **Workspace → Spaces → Folders → Lists → Tasks → Subtasks** (+ Checklists داخل المهمة).

| المستوى | ما هو | مثال عملي |
|---|---|---|
| **Workspace** | مساحة عملك الكاملة، الحاوية الأعلى لكل شيء؛ عادة واحدة لكل شركة | شركة «ألفا» كلها |
| **Space** | التقسيم الأكبر داخل مساحة العمل، قسم أو فريق أو مجال عمل، وله إعدادات وصلاحيات وطرق عرض خاصة | Marketing / Engineering / HR |
| **Folder** | مجموعة قوائم لمشروع أو دورة عمل داخل المساحة | حملة «إطلاق منتج 2026» |
| **List** | وحدة العمل الفعلية، هنا تعيش المهام، وهي أصغر مستوى يمكن مشاركته مباشرة | «مطلوب تصميم الشعار» |
| **Task** | المهمة الواحدة القابلة للتعيين والتتبع | «تصميم 3 مقترحات شعار» |
| **Subtask** | مهمة فرعية داخل مهمة (عمق مستويين) | «مراجعة الخطوط» |
| **Checklist** | قائمة تحقق داخل المهمة (نقاط لا تُعامل كمهام مستقلة) | خطوات نشر ملفات |

**حدود مهمة (Limits):**
- عدد المساحات Spaces لكل مساحة عمل: **5 في الخطة المجانية، غير محدود في المدفوعة** (يمكن إنشاء Spaces أرشيفية بعدها).
- الحدود الرسمية المنشورة في مركز مساعدة ClickUp: حتى **100 Folder لكل Space** تقريبًا في الاستخدام العملي، وحدود أداء موصى بها عند آلاف المهام في قائمة واحدة (ClickUp ينصح بتجاوز 5,000 مهمة/قائمة بحذر لأن الأداء يتراجع).
- المهمة الفرعية بعمق مستويين فقط (Subtask within Subtask).

مبادئ تصميم الهيكل الجيد: Space للفريق، Folder للمشروع، List لمرحلة أو نوع عمل، ولا تكرر نفس البنية مرتين.

## 3. المهام (Tasks)

- **الإنشاء**: زر `+ New Task` أو اختصار `T` في أي قائمة؛ عنوان + وصف غني (Rich text) + صور ومرفقات (سحب وإفلات) + تعيين + تاريخ + أولوية.
- **الحالات Status**: الافتراضية Open / In Progress / Closed (قابلة للتخصيص بالكامل لكل قائمة: To Do, In Review, Blocked...).
- **التعيين**: شخص واحد أو **عدة أشخاص (Multi-assign)** في الخطط المدفوعة.
- **الأولويات الأربع**: 🔴 Urgent، 🟠 High، 🔵 Normal، ⚪ Low (قابلة لإعادة التسمية).
- **التواريخ**: تاريخ بدء + استحقاق، أوقات محددة، مدد، وتواريخ **متكررة Recurring** بجدولة (يومي/أسبوعي/مخصص مثل «كل يوم اثنين ثالث كل شهر»).
- **المراقبون Watchers**: يُبلَغون بأي تحديث على المهمة.
- **التعليقات**: تعليقات غنية، إسناد تعليق (Assigned comment) يحوّل التعليق إلى بند عمل، ردود بريدية، ومقاطع شاشة/فيديو (Clips).
- **العلاقات**: **Waiting on / Blocking** (اعتمادية تجعل المهمة لا تُبدأ قبل انتهاء أخرى)، Linked tasks بين قوائم مختلفة.
- **التحقق Checklists**: عناصر متعددة، إسناد عنصر لنفسك، تقدم بنسبة مئوية تلقائي.

## 4. طرق العرض (Views)، نفس البيانات، 15+ طريقة رؤية

| العرض | ماذا يعرض | الأفضل لـ |
|---|---|---|
| **List** | مهام مرتبة/مجمّعة/مفلترة | اليومية والتفاصيل |
| **Board (Kanban)** | أعمدة = حالات | سير العمل البصري للفرق |
| **Calendar** | شبكة شهر/أسبوع بالتواريخ | الجدولة والمواعيد |
| **Timeline / Gantt** | خط زمني بالاعتماديات + المسار الحرج | خطط المشاريع المعقدة |
| **Table** | جدول Excel مع أعمدة قابلة للفرز | جرد البيانات والتقارير السريعة |
| **Mind Map** | تحويل قوائم/مهام إلى خريطة ذهنية تفاعلية | العصف الذهني والتخطيط |
| **Workload** | عبء كل شخص (Business+) | موازنة التوزيع |
| **Activity** | سجل كل التحديثات | المراجعة والمساءلة |
| **Chat view** | دردشة مدمجة حول قائمة/مجلد | مناقشات المشروع داخل سياقه |
| **Form** | نموذج يجمع طلبات كمهام | طلبات العمل والاستبيانات |
| **Doc view** | مستند مربوط بالمكان | توثيق المشروع |
| **Embed** | محتوى خارجي (Figma, YouTube, Sheets) | مركزية الأدوات |

كل Space/Folder/List يمكن أن يحتوي عدة Views (مجموعة Views بمجموعة خاصة)، ويمكن حفظ فلتر/مجموعة/فرز كعرض دائم ومشاركته.

## 5. الحقول المخصصة (Custom Fields)

أقوى ميزة تمييز في ClickUp: تحوّل أي قائمة إلى «قاعدة بيانات» تشبه Airtable.

**الأنواع (18+)**: Text, Number, Currency, Percent, Date, Dropdown (خيار واحد), Labels (متعدد), Checkbox, URL, Email, Phone, Rating (نجوم), Progress, Formula (معادلات تشير لحقول أخرى), Location, Button (تشغيل أتمتة بضغطة), Relationship (ربط مهام/قوائم), Auto ID (رقم تسلسلي).

- تُضاف على مستوى **قائمة أو مجلد أو مساحة أو مساحة عمل كاملة**؛ الحقل المكاني Space Field يورَّث لكل قوائم المساحة (أضيف في 2024–2025) فيضمن توحيد البيانات.
- تظهر كأعمدة في List/Table، وفلاتر، وتجميعات، ورسوم في Dashboards.

## 6. القوالب (Templates)

- قوالب لكل شيء: **مهام، مهام فرعية، قوائم، مجلدات، مساحات كاملة، Views، Docs، Checklists، الأتمتة**.
- مكتبة قوالب رسمية جاهزة (100+ سيناريو: Sprint، حملة تسويق، توظيف، إطلاق منتج...).
- **متغيرات القوالب**: `{{assignee}}`, `{{due_date}}`, `{{list_name}}`... تُستبدل تلقائيًا عند التطبيق.

## 7. اختصارات لوحة المفاتيح (الأهم)

`T` مهمة جديدة · `Shift+T` مهمة فرعية · `A` تعيين لي · `S` حالة · `P` أولوية · `D` تاريخ · `Ctrl/Cmd+K` البحث السريع / Quick Actions · `Ctrl/Cmd+/` لوحة الاختصارات الكاملة · `U` فتح آخر مهمة أُنشئت · `F` فلتر سريع.

## 8. أول 15 دقيقة لمستخدم جديد (الإعداد العملي بالترتيب)

1. أنشئ حسابًا وأجب عن أسئلة Onboarding (اختر قالب مساحة عمل جاهز مثل «Personal» أو «Product Team»).
2. سمِّ Workspace باسم شركتك/مجالك وادعُ 1–3 زملاء للتجربة.
3. أنشئ أول **Space** (مثال: «العمل اليومي» أو «مشروع تجريبي») واختر خصوصيته.
4. أنشئ **List** داخل المساحة («قائمة تجربة») وأضف 3 مهام حقيقية من عملك الفعلي.
5. جرّب على المهام: تعيين + تاريخ + أولوية + حالة.
6. أضف **Board view** بجانب List وشاهد نفس المهام كبطاقات كانبان.
7. أنشئ **Custom Field** واحد (مثال: Dropdown «نوع العمل») لتفهم المفهوم.
8. فعّل أتمتة واحدة جاهزة (مثال: عند تغيير الحالة إلى Done → إغلاق المهمة تلقائيًا).
9. حمّل تطبيق الجوال/سطح المكتب وامتداد Chrome.
10. قسّم أول أسبوع عمل حقيقي: List أسبوعية + عرض Calendar.
