# ClickUp Master Guide - موقع الدليل الشامل ثنائي اللغة

موقع تعليمي مرجعي كامل يشرح أداة إدارة المشروعات **ClickUp** شرحًا تفصيليًا شاملًا - بالعربية والإنجليزية في صفحة واحدة ثنائية اللغة.

## ▶️ التشغيل / How to run

لا يحتاج أي تثبيت أو خادم:

1. افتح الملف `index.html` في أي متصفح حديث (Chrome / Safari / Edge / Firefox).
2. بدّل اللغة من مبدّل **العربية / English** أعلى الصفحة (يُحفظ اختيارك تلقائيًا، ويمكن تثبيت اللغة بمعامل الرابط `?lang=en` أو `?lang=ar`).
3. للنشر: ارفع مجلد `clickup-guide/` كاملًا إلى أي استضافة ثابتة (GitHub Pages / Netlify / Vercel / Cloudflare Pages) - موقع ثابت 100% بدون خادم.

## 🗂️ بنية الملفات

```
clickup-guide/
├── index.html              ← الصفحة الرئيسية (كل المحتوى ثنائي اللغة)
├── css/style.css           ← نظام التصميم (Preset: 11 Build)
├── js/app.js               ← التفاعل: تبديل اللغة، الفهرس، الأكورديون، التقدم
├── assets/
│   ├── research-basics.md  ← مادة مرجعية: الأساسيات (عربي)
│   └── research-pricing.md ← مادة مرجعية: الأسعار والمقارنات (عربي)
└── README.md

## 🎮 تعديل المحاكاة الحية

- **المهام الافتراضية**: مصفوفة `SIM_DEFAULT` في `js/app.js` (عنوان ثنائي اللغة، حالة، أولوية، مسؤول، يوم استحقاق).
- **الحالات والأشخاص**: مصفوفتا `SIM_STATUSES` و`SIM_PEOPLE`.
- **الأتمتة عند الإكمال**: دالة `simFireAutomation` (نص اللافتة قابل للتعديل).
- تظهر المحاكاة تلقائيًا في الفهرس لأن القسم له `id="simulator"` ومسجل في `SECTION_IDS`.

## 📖 كيف تضيف مصطلحًا للمسرد

افتح `js/app.js` وأضف سطرًا في مصفوفة `GLOSSARY`:

```js
{ en: 'Term', ar: 'المصطلح', d_ar: 'الشرح بالعربية', d_en: 'English explanation' },
```

سيظهر تلقائيًا في شبكة المسرد، ويتعرف عليه التلميح الفوري داخل النصوص التي تحتوي المصطلح نفسه.
```

## ✍️ كيف تعدّل المحتوى

- **نص الموقع**: كل قسم في `index.html` يحتوي نسختين - `<div class="lang-en">` و `<div class="lang-ar">`. عدّل النص داخل النسختين معًا لتظل اللغتان متطابقتين.
- **قائمة المحتويات**: آلية بالكامل - أي قسم جديد `id="xxx"` داخل `<section class="section">` يظهر فورًا في الفهرس (أضف الـ id إلى `SECTION_IDS` في `js/app.js` لتفعيل تظليل القسم النشط).
- **الأسعار**: داخل قسم `#pricing` في `index.html`. حدّثها من المصدر الرسمي clickup.com/pricing عند تغيرها.
- **الألوان والخطوط**: متغيرات `:root` في أول `css/style.css`.
- **إضافة قسم**: انسخ أي `<section>` وأعد الترقيم في `.sec-num`، ثم أضف الـ id لـ `SECTION_IDS` في `app.js`.

## ✨ الميزات التفاعلية

- **تبديل عربي/English** مع انعكاس الاتجاه RTL/LTR وحفظ الاختيار (localStorage + معامل `?lang=`).
- **مسرد مصطلحات** (32 مصطلحًا): شبكة قابلة للبحث في قسم "المسرد" + تلميحات فورية عند تمرير المؤشر على المصطلحات داخل النصوص.
- **بحث فوري** بزر في الترويسة أو `Ctrl/Cmd+K`: نتائج لحظية من محتوى الصفحة باللغة النشطة مع إبراز الكلمة والانتقال للقسم.
- **محاكاة حية لمساحة عمل ClickUp** (قسم 05): لوحة كانبان بسحب وإفلات حقيقي بين 4 حالات، وتبديل بين List/Board/Calendar/Table لنفس البيانات، وإضافة مهام، وإكمال من القائمة، وأتمتة تنطلق بلافتة خضراء عند الإكمال، وزر إعادة ضبط. الواجهة LTR عمدًا لتعكس الشكل الحقيقي للأداة.
- **فهرس جانبي** يظلل القسم الحالي + درج للجوال + شريط تقدم قراءة + أكورديون للأسئلة الشائعة + زر العودة للأعلى.

## ✅ ما تم فحصه

- فتح الموقع محليًا عبر خادم HTTP والتحقق من التحميل (HTTP 200) وعدم وجود أخطاء JS (فحص node --check ناجح).
- التبديل العربي ⇄ الإنجليزي: إخفاء/إظهار الكتل، اتجاه الصفحة RTL/LTR، عنوان الصفحة والوصف.
- حفظ اللغة في localStorage + معامل الرابط `?lang=`.
- فهرس جانبي مع تظليل القسم الحالي، درج فهرس للجوال، شريط تقدم القراءة.
- أكورديون الأسئلة الشائعة (فتح/إغلاق/إغلاق الإخوة تلقائيًا).
- تجاوب على عرض الجوال (390px) والحاسب (1440px).
- محتوى عربي كامل مكافئ للإنجليزي في كل الأقسام الـ 19.
- المحاكاة: اختبار منطق السحب والإفلات والتبديل بين العروض وإطلاق الأتمتة وإعادة الضبط على مستوى الكود + فحص بنية HTML.
- مراجعة صرمة للصياغة: إزالة كل الشرطات الطويلة وبصمات الصياغة الآلية، والإبقاء فقط على الشرطة القصيرة في النطاقات الرقمية القياسية (مثل 1–5).
